# قوائم التحقق قبل التسليم

## قائمة 1 — قبل كل مهمة

- [ ] أعدت صياغة المهمة (هدف/قيود/خارج النطاق/تعريف "تمّ")؟
- [ ] فحصت `git status`؟
- [ ] فهمت إيش اللي موجود فعلًا قبل ما تكتبه؟

## قائمة 2 — قبل القول "تمّ"

- [ ] typecheck مرّ بدون أخطاء؟
- [ ] الاختبارات شغّلت ونجحت؟ **(شغّلها فعليًا، مش افترض)**
- [ ] `git status` — مفيش ملفات زائدة أو ناقصة؟
- [ ] الوصف بيقول: إيش اشتُغل، وإيش ما اشتُغل، وإيش الباقي؟

**القاعدة:** لو خطوة ما شغّلتها، قلها بصراحة. الاختبار اللي ما شغّلش = لم ينجح ولم يفشل.

## قائمة 3 — بعد ما يغيّر الموديل

- [ ] قرأت `skills-hub/master/SKILL.md` كامل؟
- [ ] قرأت `AGENTS.md`؟
- [ ] فحصت `git status` + `git diff --stat`؟
- [ ] حددت أول خطوة **غير مكتملة** من الخطة بفحص، مش بذاكرة؟

**ممنوع** تبدأ من مكان "تتذكره". الموديل مش بيتذكر — المستودع هو الذاكرة.

## قائمة 4 — مراجعة الكود

- [ ] مفيش كود مكرر عنده موجود أصلًا؟
- [ ] مفيش `any` ولا `@ts-ignore`؟
- [ ] التعليقات بتشرح "ليه" مش "إيش"؟
- [ ] أصغر تغيير ممكن اتنفذ، مش إعادة هيكلة؟
- [ ] مفيش أسرار اتسجلت في أي مكان؟
